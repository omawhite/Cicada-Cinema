# Brand fonts

Web-licensed `.woff2` files go here once obtained from the designer/foundry.
Not yet added — see `@font-face` declarations in `src/global.css` for the
expected filenames. Until these files exist, `Reuben` and `Florensans` fail
to load and the site falls back to the system sans-serif stack.

Expected files:

- `reuben-regular.woff2`
- `florensans-regular.woff2`

Do not commit desktop `.otf`/`.ttf` files or the Illustrator/EPS masters —
those live in shared storage, not the repo.
